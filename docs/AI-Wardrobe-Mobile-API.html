AI Wardrobe — Mobile API Reference

Connect Android / iOS to the backend  ·  Production base URL: https://appworkspro.com

1. How every response works

All /api/v1/* JSON endpoints use the same envelope:

{
  "data": { ... },   // present on success
  "error": null
}

// On failure:
{
  "data": null,
  "error": { "code": "VALIDATION", "message": "..." }
}

Your app should: parse JSON → if error !== null show message → else use data.

2. Headers

HeaderValue
Content-Typeapplication/json on POST/PATCH
AuthorizationBearer <access_token> after login
X-App-LocaleOptional: en, ur, …

3. Authentication

Google Sign-In (Android)

POST /api/v1/auth/google
{
  "id_token": "<from Google Sign-In SDK>",
  "device_id": "optional"
}

200 data

{
  "access_token": "eyJ...",
  "refresh_token": "eyJ...",
  "expires_at": "2026-09-28T12:00:00.000Z",
  "token_type": "Bearer",
  "user": {
    "id": "...",
    "email": "user@gmail.com",
    "display_name": "Name",
    "photo_url": "https://...",
    "role": "user"
  }
}

Email register / login

POST /api/v1/auth/register
{ "email": "...", "password": "min8chars", "display_name": "..." }
POST /api/v1/auth/login
{ "email": "...", "password": "..." }

Same token + user object as Google. Admin accounts cannot use /auth/login.

Refresh token

POST /api/v1/auth/refresh
{ "refresh_token": "..." }
{
  "access_token": "...",
  "refresh_token": "...",
  "expires_at": "...",
  "token_type": "Bearer"
}

Store the new refresh token after each refresh.

4. App flow (recommended)

  1. GET /api/v1/app/metadata — version, feature flags
  2. GET /api/v1/languages · GET /api/v1/onboarding/pages
  3. Login → save access_token + refresh_token
  4. POST /api/v1/devices/register — FCM token
  5. GET /api/v1/home/feed?gender=women
  6. GET /api/v1/catalog/virtual_try_on — list styles
  7. Try-on → generate → poll job → save history

6. Virtual try-on

POST /api/v1/try-on/generate

Auth required

{
  "source_image_base64": "data:image/jpeg;base64,...",
  "style_id": "style-01",
  "category_id": "virtual_try_on",
  "width": 768,
  "height": 1024
}

200 data

{
  "job_id": "66f1...",
  "polling_url": "/api/v1/try-on/jobs/66f1...",
  "status": "queued"
}
GET /api/v1/try-on/jobs/{job_id}

Poll every 2–3s until status is completed or failed.

{
  "job_id": "66f1...",
  "status": "completed",
  "result_image_url": "/uploads/looks/.../result.png",
  "result_image_absolute_url": "https://appworkspro.com/uploads/looks/.../result.png",
  "error": null
}
statusAction
queued / processingKeep polling
completedShow result_image_absolute_url
failedShow error

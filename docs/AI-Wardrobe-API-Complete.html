Base URL: https://appworkspro.com  |  Prefix: /api/v1  |  Envelope: { "data", "error" }

1. Response envelope

Success: { "data": { ... }, "error": null }
Failure: { "data": null, "error": { "code": "UNAUTHORIZED", "message": "..." } }

2. Access token (~10 min) & interceptor

ItemValue
Access token TTL600 seconds (10 minutes) — env ACCESS_TOKEN_TTL_SECONDS
Refresh token TTL30 days — rotates on each refresh
HeaderAuthorization: Bearer <access_token>

App must implement

  1. Proactive: call POST /auth/refresh ~1 min before access expires.
  2. Reactive: on 401, refresh once, retry request once (mutex so only one refresh runs).
  3. Save new refresh_token every time.
  4. Refresh returns 401 → clear storage → login screen.
POST /api/v1/auth/refresh
{ "refresh_token": "..." }

200 data: { "access_token", "refresh_token", "expires_at", "token_type": "Bearer" }

OkHttp: skip interceptor for

/auth/login, /auth/register, /auth/google, /auth/refresh, /auth/admin/login
